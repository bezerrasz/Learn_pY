# 🧪 Repositório de Estudos e Testes

👋 Olá! Bem-vindo ao meu repositório.

Este espaço foi criado exclusivamente para **fins de estudo, testes e aprendizado**. Nada por aqui é um projeto finalizado ou pronto para uso em produção. É o meu laboratório pessoal! 

Estou utilizando este repositório para salvar meus progressos, testar códigos e aprender na prática o controle de versão com o Git/GitHub.

## 🛠️ O que estou explorando aqui?
Atualmente, os códigos deste repositório envolvem testes com:
* **Interfaces Gráficas em Python:** Criando telas e botões utilizando a biblioteca `PySide6` e arquitetura com Controllers.
* **Estudos de LLM (Inteligência Artificial):** Scripts focados em processamento de textos, como a criação de tokenizadores personalizados (`SimpleTokenizer`) a partir de textos brutos, leitura de vocabulários e download automático de arquivos via `requests`.

## 🚀 Aviso
Como estou aprendendo, os arquivos podem ser alterados, renomeados ou até mesmo quebrar de um *commit* para o outro. 😅
